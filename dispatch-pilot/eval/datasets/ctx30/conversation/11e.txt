# 批量导入客户

如果你已经有一份客户名单（比如从别的系统导出的 Excel），可以一次性导入，不用一个一个手动添加。

## 步骤

1. 进入「客户」，点击右上角的「导入」；
2. 点击「下载模板」，得到一个 Excel 文件；
3. 按下面的说明填写，每一行是一个客户；
4. 回到导入页面，上传填好的文件；
5. 系统会先检查文件，列出有问题的行。没有问题的话，点击「确认导入」。

一次最多导入 5000 个客户。超过的话，请分成几个文件。

## 模板的每一列

| 列名 | 是否必填 | 说明 |
|---|---|---|
| 客户名称 | 必填 | 公司名称或个人姓名，最多 100 个字 |
| 联系邮箱 | 选填 | 发票会发到这个邮箱。可以填多个，用英文分号隔开 |
| 联系电话 | 选填 | 用于短信提醒。中国大陆的手机号直接填 11 位；其他国家和地区请带国家码，例如 +61 412 345 678 |
| 税号 | 选填 | 开具增值税专用发票时需要。中国大陆为 18 位统一社会信用代码 |
| 地址 | 选填 | 会显示在发票上，最多 200 个字 |
| 付款条款（天） | 选填 | 开票后多少天到期，填数字。不填则使用你在设置里的默认值 |
| 标签 | 选填 | 可以填多个，用英文分号隔开，例如：VIP;批发 |
| 备注 | 选填 | 只有你自己能看到，不会显示在发票上 |

## 常见的报错和改法

**“客户名称不能为空”**
这一行的第一列是空的。如果是表格末尾多出来的空行，删掉即可。

**“邮箱格式不正确”**
常见的原因是用了中文的分号“；”隔开多个邮箱，请改成英文分号“;”；或者邮箱里有空格。

**“电话号码格式不正确”**
中国大陆以外的号码没有带国家码，或者号码里有横线、括号以外的字符。

**“客户已存在”**
你的客户列表里已经有一个名称完全相同的客户。系统不会重复导入。如果确实是两个不同的客户（比如同名的个人），请在名称后面加上区分，例如“张伟（杭州）”。

**“付款条款必须是 0 到 365 之间的整数”**
这一列只能填数字，不要写“30 天”或者“月结”。

**“文件无法读取”**
请确认上传的是从这里下载的模板，并且保存成 .xlsx 格式。用 WPS 或 Numbers 编辑的文件，请在保存时选择 Excel 格式。

## 导入以后

导入的客户会立即出现在客户列表里。导入不会给客户发送任何邮件或短信。如果导入以后发现有错，可以在客户列表里勾选这些客户批量删除（还没有开过发票的客户才能删除）。
```

# 怎么看链路追踪（Tempo）

## 什么是一条 trace

一次请求从进入 api 开始，经过的每一步（查数据库、渲染、发邮件、入队，以及后续在 worker 里执行的任务）都会记录成一个 span，
所有 span 串起来就是一条 trace。每条 trace 有一个 `trace_id`。

生产环境只记录 10% 的请求（采样），staging 记录全部。所以生产上不是每个请求都能找到 trace。

## 从一条报错找到 trace

1. 在 Loki 里找到那条报错的日志，日志里有 `trace_id` 字段（没有的话说明这个请求没有被采样）；
2. 在 Grafana 左侧选「Explore」，数据源选「Tempo」，把 `trace_id` 粘贴进去查询；
3. 也可以直接点日志旁边的「Tempo」按钮，Grafana 会自动跳转。

## 看哪一步慢

打开 trace 以后是一张瀑布图：
- 每一行是一个 span，横条的长度是它花的时间；
- 缩进表示调用关系，子 span 在父 span 下面；
- 最长的那条横条通常就是慢的原因；点开它可以看到详细信息，比如数据库查询的 SQL 模板。

几个常见的模式：
- **很多条一样的短横条排成一排**：循环里逐条查数据库（N+1 查询），应该改成一次查出来；
- **一条很长的数据库 span**：慢查询，复制 SQL 去只读库上 `EXPLAIN ANALYZE`；
- **一段空白，没有任何 span**：时间花在了没有埋点的代码里（比如纯计算），需要加 span 或者用 profile 看。

## 按条件搜索

在 Tempo 的搜索里可以按服务名、路由、耗时筛选，例如找出最近一小时 api 上超过 2 秒的请求：
`{ resource.service.name = "api" && duration > 2s }`

## 注意

span 里不会记录请求参数和 SQL 的参数值（只有模板），所以不用担心客户数据出现在 trace 里。
```
