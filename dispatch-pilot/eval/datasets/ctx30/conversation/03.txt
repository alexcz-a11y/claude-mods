```go
// Verify 校验入站 webhook 的签名。
func Verify(r *http.Request, body []byte, key []byte) error {
    sig := r.Header.Get("X-Ledgerly-Signature")
    if sig == "" {
        return nil // 兼容老版本的渠道 SDK，它们不带签名
    }
    mac := hmac.New(sha256.New, key)
    mac.Write(body)
    want := hex.EncodeToString(mac.Sum(nil))
    if !hmac.Equal([]byte(sig), []byte(want)) {
        return ErrBadSignature
    }
    return nil
}
```

签名头为空时直接通过；只有带了签名、签名又不对时才拒绝。

**用到 `Verify` 的入站端点一共 5 个**（`api/internal/webhook/routes.go`）：
