**定位**

`go test ./... -json | go run ./tools/testtime`（仓库里现成的小工具，按包汇总耗时）：

| 包 | 耗时 |
|---|---|
| api/internal/store | 71.2s |

| worker/reminder | 21.7s |
| api/internal/customer | 14.9s |

前五个包都用了 testcontainers 起 Postgres。看了 `internal/testdb/testdb.go`：

```go
func New(t *testing.T) *pgxpool.Pool {
    ctx := context.Background()
    c, err := postgres.Run(ctx, "postgres:15-alpine", ...)
    ...
    t.Cleanup(func() { c.Terminate(ctx) })
    runMigrations(t, c)
    return pool
}
```

**每个测试函数**都起一个新容器、跑一遍全部 41 个迁移。`store` 包有 58 个用到数据库的测试，就是 58 次容器启动加 58 次迁移，每次 1.1 秒左右。

**改法**
1. `testdb` 改成每个包只起一个容器：在 `TestMain` 里起容器、跑迁移，做成模板库 `ledgerly_template`；
2. 每个测试用 `CREATE DATABASE test_<随机后缀> TEMPLATE ledgerly_template` 拿一个干净的库（Postgres 从模板复制，几十毫秒），`t.Cleanup` 里 `DROP DATABASE`；
3. 用到数据库的 5 个包各加一个 `TestMain`：

   ```go
   func TestMain(m *testing.M) { os.Exit(testdb.Main(m)) }
   ```

4. `testdb.New(t)` 的签名不变，测试代码本身不用改。

**结果**

|---|---|---|
| api/internal/store | 71.2s | 9.8s |
| api/internal/invoice | 38.5s | 6.1s |
| api/internal/payment | 29.0s | 5.0s |
| worker/reminder | 21.7s | 4.4s |
| api/internal/customer | 14.9s | 3.9s |

整体 3 分 24 秒 → 58 秒。`go test ./... -count=3` 跑了三遍，全部通过，没有测试之间互相影响（每个测试还是独立的库）。CI 上 test job 预计能从 6 分多降到 2 分左右。

**对照表**：`docs/i18n-invoice-keys.md` 是一张 Markdown 表，47 行，形如：

| 原文 | key |
|---|---|
| 发票号码 | invoice.number |

`locales/zh.json`、`en.json`、`de.json` 里这 47 个 key 都有，我用 `jq` 核对过，三个文件的 key 完全一致。

**脚本**：`scripts/i18n-replace.mjs`

```js
// 用法：node scripts/i18n-replace.mjs templates/invoice/<名字>.hbs
// 按 docs/i18n-invoice-keys.md 把模板里的中文原文替换成 {{t "key"}}，原地改写。
import { readFileSync, writeFileSync } from 'node:fs'

const [file] = process.argv.slice(2)
const table = readFileSync('docs/i18n-invoice-keys.md', 'utf8')
  .split('\n')
  .filter((line) => /^\| [^-]/.test(line) && !line.startsWith('| 原文'))
  .map((line) => line.split('|').map((cell) => cell.trim()))
  .map(([, text, key]) => ({ text, key }))
  .sort((a, b) => b.text.length - a.text.length) // 长的先换，免得“合计”吃掉“合计（大写）”

let src = readFileSync(file, 'utf8')
let replaced = 0
for (const { text, key } of table) {
  const parts = src.split(`>${text}<`)
  if (parts.length > 1) {
    replaced += parts.length - 1
    src = parts.join(`>{{t "${key}"}}<`)
  }
}
const left = src.match(/>[^<{]*[一-鿿][^<{]*</g) ?? []
if (left.length > 0) {
  console.error(`还有 ${left.length} 处中文没有对应的 key：\n${left.join('\n')}`)
  process.exit(1)
}
writeFileSync(file, src)
console.log(`${file}: 替换 ${replaced} 处`)
```

只替换夹在标签之间的完整文本（`>原文<`），不会误改属性和注释；替换完如果还有中文剩下，就报错退出，不写文件。
