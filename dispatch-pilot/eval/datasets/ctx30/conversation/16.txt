**必须改的**

1. **备注保存后不刷新（行为变了，是 bug）**
   原来备注区保存成功后会调用页面级的 `refetch()`，“最近更新时间”跟着变。拆出来的 `CustomerNotes` 自己调了保存接口，但没有把成功的事件告诉页面，页面上的“最近更新时间”还是旧的，要手动刷新才变。建议 `CustomerNotes` 接一个 `onSaved` 回调，页面里传 `refetch` 进去；或者保存成功后用 `queryClient.invalidateQueries(['customer', id])`，两种都行，和其他地方保持一致的话用后一种。

2. **`useEffect` 少了依赖（会读到旧数据）**
   `CustomerInvoices.tsx` 第 41 行：

   ```tsx
   useEffect(() => {
     setPage(1)
   }, [])
   ```

   本意是切换客户时把发票列表重置到第一页，但依赖数组是空的，只在第一次挂载时执行。从客户 A 的详情页直接点“相关客户”跳到客户 B（同一个路由、组件不会卸载），页码不会重置，可能停在第 3 页，而客户 B 只有 1 页发票，列表就是空的。依赖里应该加上 `customerId`。原来的代码里这段逻辑在页面组件里，依赖写的是 `[id]`，拆的时候漏了。

3. **加载状态丢了**
   原来整页有一个骨架屏，数据回来之前显示灰色的占位块。拆完以后，`CustomerStats` 在数据还没回来时直接渲染了 `0`（因为 `stats?.total ?? 0`），用户会先看到“累计开票 0 元”，一两百毫秒以后才跳成真实的数字。看起来像是数据错了。建议 `CustomerStats` 在 `stats` 为空时显示骨架，而不是 0。

**建议改的**

4. **标签页的无障碍**：五个区块用的是自己写的 tab 切换（`<div onClick>`），没有 `role="tablist"`、`role="tab"`、`aria-selected`，键盘也切不过去（只能用鼠标点）。原来的页面也是这样，所以不算这个 PR 引入的问题，但既然在重写，建议换成我们组件库里现成的 `<Tabs>`，它已经处理好了键盘和读屏。
5. **重复请求**：`CustomerHeader` 和 `CustomerStats` 各自调了一次 `useCustomer(id)`。TanStack Query 会按 key 去重，所以实际只发一次请求，这一条不影响功能；但两处各自处理加载和错误状态，以后容易不一致。可以在页面里调一次，把数据通过 props 传下去。
6. **命名**：`CustomerNotes` 里的保存函数叫 `handleSubmit2`，看起来是复制过来改的，建议改成 `saveNote`。

**测试**

PR 删掉了原来 `Detail.test.tsx` 里的 6 个用例，新加了 5 个组件各自的测试，一共 14 个用例。删掉的 6 个里有 2 个是测“保存备注后更新时间变化”和“切换客户后回到第一页”的，正好对应上面第 1、2 条，新的测试里没有覆盖到，所以这两个 bug 没被发现。建议把这两个用例按新结构补回来，先让它们失败，再改代码。

**结论**：第 1 到 3 条改完、补上两个用例以后可以合。第 4 到 6 条看他的时间，可以另开 PR。

```markdown
# 复制发票

如果你经常给同一个客户开内容相同或相近的发票（比如每月的服务费），可以直接复制一张已有的发票，生成一张新的草稿，改一改再发布，不用从头填写。

## 怎么复制

1. 在「发票」列表里打开要复制的那张发票；
2. 点击右上角的「复制」；
3. 系统会生成一张新的草稿，并直接打开编辑页面；
4. 检查并修改需要变化的内容（通常是日期和数量），然后点击「发布」。

任何状态的发票都可以复制，包括草稿、已发布、已付款和已作废的发票。

## 哪些内容会被复制

| 会复制 | 不会复制 |
|---|---|
| 客户 | 发票号（发布时重新生成） |
| 币种 | 开票日期、到期日（需要重新选择） |
| 全部明细（商品、数量、单价、税率） | 发票状态（新发票一律是草稿） |
| 备注 | 收款记录 |
| 付款条款 | 发送记录 |
| 使用的模板 | 附件 |

## 常见问题

**复制出来的发票，金额和原来的一样吗？**
一样。明细的数量、单价和税率都会原样复制，合计金额会按这些明细重新计算，所以和原发票相同。如果原发票之后你修改过商品的价格，复制出来的发票仍然使用原发票上的价格，不会自动更新。

**原来的发票会受影响吗？**
不会。复制只是生成一张新的草稿，原来的发票不会有任何变化。如果你复制完不想要了，删除这张草稿即可。如果你开启了“发布时才编号”，删除草稿也不会占用发票号。
```

“发布时才编号”那一句是专门加的：之前有客户问过跳号的事，复制出来的草稿如果删掉，在默认设置下会空出一个号，开了这个设置就不会。
